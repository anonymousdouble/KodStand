The ESLint rule "key-spacing" has several configurable options. Here are the details for each option:

1. **Option Name**: beforeColon
   - **Option Description**: Controls spacing before the colon in object literals.
   - **Data Type**: boolean
   - **Data Range**: {true, false}
   - **Default Value**: false

2. **Option Name**: afterColon
   - **Option Description**: Controls spacing after the colon in object literals.
   - **Data Type**: boolean
   - **Data Range**: {true, false}
   - **Default Value**: true

3. **Option Name**: mode
   - **Option Description**: Defines the mode for spacing around colons in object literals.
   - **Data Type**: string
   - **Data Range**: {"strict", "minimum"}
   - **Default Value**: "strict"

4. **Option Name**: align
   - **Option Description**: Enforces horizontal alignment of values or colons in object literals.
   - **Data Type**: string
   - **Data Range**: {"value", "colon"}
   - **Default Value**: no default

5. **Option Name**: align

7. **Option Name**: align.afterColon
