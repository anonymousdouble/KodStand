The ESLint rule "class-methods-use-this" has two configurable options: `exceptMethods` and `enforceForClassFields`. Here are the details for each option:

1. **Option Name**: exceptMethods
   - **Option Description**: Allows specified method names to be ignored by this rule.
   - **Data Type**: array
   - **Data Range**: open-ended
   - **Default Value**: no default

2. **Option Name**: enforceForClassFields
   - **Option Description**: Enforces that functions used as instance field initializers utilize `this`.
   - **Data Type**: boolean
   - **Data Range**: {true, false}
   - **Default Value**: true
