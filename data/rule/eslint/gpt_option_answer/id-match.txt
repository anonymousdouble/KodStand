The ESLint rule "id-match" has several configurable options. Here are the details of each option:

1. **Option Name**: anonymous_option_1
   - **Option Description**: Specifies the regular expression that identifiers must match.
   - **Data Type**: string
   - **Data Range**: open-ended
   - **Default Value**: no default

2. **Option Name**: properties
   - **Option Description**: Determines whether object properties should be checked against the specified regular expression.
   - **Data Type**: boolean
   - **Data Range**: {true, false}
   - **Default Value**: false

3. **Option Name**: classFields
   - **Option Description**: Determines whether class field names should be checked against the specified regular expression.
   - **Data Type**: boolean
   - **Data Range**: {true, false}
   - **Default Value**: false

4. **Option Name**: onlyDeclarations
   - **Option Description**: Determines whether only variable, function, and class declarations should be checked against the specified regular expression.
   - **Data Type**: boolean
   - **Data Range**: {true, false}
   - **Default Value**: false

5. **Option Name**: ignoreDestructuring
   - **Option Description**: Determines whether destructured identifiers should be checked against the specified regular expression.
   - **Data Type**: boolean
   - **Data Range**: {true, false}
   - **Default Value**: false
