The ESLint rule "array-bracket-newline" has both string and object options. Here are the extracted details of the configurable options:

### String Options:
1. **Option Name**: anonymous_option_1
   - **Option Description**: Requires or disallows line breaks inside brackets.
   - **Data Type**: string
   - **Data Range**: {"always", "never", "consistent"}
   - **Default Value**: no default

### Object Options:
1. **Option Name**: anonymous_option_2
   - **Option Description**: Requires line breaks if any of the properties is satisfied. Otherwise, disallows line breaks.
   - **Data Type**: object
   - **Data Range**: null
   - **Default Value**: no default

2. **Option Name**: anonymous_option_2.multiline
   - **Option Description**: Requires line breaks if there are line breaks inside elements or between elements.
   - **Data Type**: boolean
   - **Data Range**: {true, false}
   - **Default Value**: true

3. **Option Name**: anonymous_option_2.minItems
   - **Option Description**: Requires line breaks if the number of elements is at least the given integer.
   - **Data Type**: integer
   - **Data Range**: {0, null, any positive integer}
   - **Default Value**: null
