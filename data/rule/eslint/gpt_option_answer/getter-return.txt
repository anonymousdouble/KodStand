The ESLint rule "getter-return" has one configurable option, which is an object option. Here are the details of the configurable option:

1. **Option Name**: anonymous_option_1
   - **Option Description**: Disallows implicitly returning `undefined` with a `return` statement.
   - **Data Type**: object
   - **Data Range**: {"allowImplicit": boolean}
   - **Default Value**: no default

2. **Option Name**: anonymous_option_1.allowImplicit
   - **Option Description**: Allows implicitly returning `undefined` with a `return` statement.
   - **Data Type**: boolean
   - **Data Range**: {true, false}
   - **Default Value**: false
