The ESLint rule "no-bitwise" has two configurable options. Here are the details:

1. **Option Name**: allow
   - **Option Description**: Allows a list of bitwise operators to be used as exceptions.
   - **Data Type**: array
   - **Data Range**: open-ended
   - **Default Value**: no default

2. **Option Name**: int32Hint
   - **Option Description**: Allows the use of bitwise OR in `|0` pattern for type casting.
   - **Data Type**: boolean
   - **Data Range**: {true, false}
   - **Default Value**: no default
