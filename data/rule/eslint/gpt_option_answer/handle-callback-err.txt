The ESLint rule "handle-callback-err" has one configurable option. Here are the details:

1. **Option Name**: anonymous_option_1
   - **Option Description**: The name of the error parameter.
   - **Data Type**: string
   - **Data Range**: open-ended
   - **Default Value**: "err"

Additionally, there is a more flexible configuration using regular expressions for the error parameter name:

2. **Option Name**: anonymous_option_1 (with regular expression)
   - **Option Description**: The name of the error parameter, specified as a regular expression.
   - **Data Type**: string (regular expression)
   - **Data Range**: open-ended
   - **Default Value**: no default

The rule does not have any nested or sub-options.
